DND UNIVERSE — a whole world for a tabletop campaign

A tabletop role-playing table in the browser: 192 characters, 9 voices synthesised on the machine itself, 288 sounds, and living maps.

Link on request

What it is

A tabletop game master does a whole studio’s work in one evening: speaking for a dozen characters, holding the map in their head, cueing the music, remembering everyone’s hit points. This application takes the technical half off them: the maps, the sound, the voices and the bookkeeping live in the browser, and the master is left with the story.

The voices are synthesised on the same machine the game runs on, and that is a money decision: a master speaks for nine characters in an evening, and paying per line turns a hobby into an invoice. It also means the table does not go silent when the network does. The maps are alive — water ripples, torches flicker — and that is not decoration but the thing that separates a table in a browser from a picture in a chat.

Specifications: Node.js and Fastify on the server, SQLite for storage, Piper for the local voices, and WebSocket so that the table changes for every player at once. It runs around the clock on my own server. The world itself is deliberately still empty: what it needs is lore and a party, not more code — and that is a statement about what is missing, not a promise about what will come.

What proves it
