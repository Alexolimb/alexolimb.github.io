Viktoriia English — a live landing page for an English tutor

A landing page for a private tutor: one page instead of a business card, a price list and a sign-up form, in two languages at once.

Open it live

What it is

A real commission. A private tutor has no sales team: the site is the only place where a person decides whether to write or not. So the page is built as one conversation — who teaches, how a lesson goes, what the child will be able to do, how long it takes — with a message button at the end of every section.

Two languages are part of the brief here, not decoration: the students are split between Ukraine and English-speaking countries, and one page has to work for both without reading like a translation. The switch changes more than the wording — it changes the order of the arguments, because what matters to a parent in Kyiv and to a parent overseas is not the same thing.

Specifications: a static site published on GitHub Pages — free hosting, nothing there to fall over, and an update is one push to the repository. The background is computed on the graphics card through WebGL; there are no raster images on the page at all, everything is drawn in code, so it loads fast and stays sharp on any screen. The source is public.
